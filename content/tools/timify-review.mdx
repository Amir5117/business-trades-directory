    advanced statistics dashboard, enterprise apps.<br />

    <strong>Enterprise Plus</strong>: Custom pricing — all Enterprise features plus Branch Manager, personalised
    booking widget, SSO with MS Azure, REST API, virtual queue management, TIMIFY Call Centre, private
    apps, dedicated onboarding and a success manager.</p>
