  - overview_listing_title: Automated Network Discovery & Mapping
    overview_listing_content: Auvik's lightweight collector auto-discovers every device on the network
      — switches, routers, firewalls, APs, printers, virtual hosts — and keeps a live, interactive topology
      map up to date as things change. You see Layer 1, 2, and 3 relationships without drawing diagrams
      by hand, which slashes onboarding time on any new site.
  - overview_listing_content: Auvik continuously polls SNMP, syslog, and APIs for performance metrics

      and stores historical baselines for trend analysis. Pre-built dashboards surface the noisy interface
      or the saturated WAN link long before users start filing tickets.
    overview_listing_title: Real-Time Network Performance Monitoring
  - overview_listing_title: Automatic Configuration Backups
    overview_listing_content: Configuration changes on every supported network device are captured, version-controlled,
      and diffed automatically inside Auvik. If a misconfiguration takes a switch offline at 2 a.m., the
      on-call engineer can roll back to the last working config in a couple of clicks instead of rebuilding
      from memory.
  - overview_listing_content: TrafficInsights runs flow analysis (NetFlow, sFlow, J-Flow) without an extra
      hardware probe and tells you which applications, users, and endpoints are eating the link. Bandwidth
      complaints turn into a couple of filters in the UI rather than a multi-day packet capture exercise.
    overview_listing_title: TrafficInsights Deep Flow Analysis
  - overview_listing_title: SaaS Management & Shadow IT Discovery
    overview_listing_content: Auvik SaaS Management discovers the SaaS apps your users are actually signing

      act on.
  - overview_listing_title: Multi-Site & Multi-Tenant Dashboards
    overview_listing_content: Auvik is built multi-tenant from the ground up, so MSPs see a single login

      running multiple offices or DCs get the same separation without standing up multiple monitoring
      stacks.
  - overview_listing_content: Granular alerting rules push to email, Slack, Teams, PagerDuty, Opsgenie,

      forcing a workflow rebuild.

  - faqs_area_content: Auvik uses a lightweight collector installed on your network that scans via SNMP,

    faqs_area_title: How does Auvik discover my network?
  - faqs_area_title: Is Auvik good for MSPs?
    faqs_area_content: Yes. Auvik is widely considered the leading network monitoring platform for MSPs,
      with multi-tenant dashboards, per-client billing data, and integrations with popular MSP tools like
      ConnectWise, Autotask, and Kaseya.
  - faqs_area_title: Does Auvik integrate with ConnectWise and Autotask?
    faqs_area_content: Yes. Auvik offers native integrations with ConnectWise Manage, ConnectWise Automate,
      Autotask PSA, Kaseya BMS, ServiceNow, Zendesk, Slack, Microsoft Teams, and a REST API for custom
      workflows.
  - faqs_area_content: Auvik pricing is quote-based and billed per billable device (typically routers,
      switches, firewalls, and access points). Most MSPs report costs between $10 and $25 per device per
      month depending on tier and volume.
    faqs_area_title: How much does Auvik cost?
  - faqs_area_title: Is Auvik secure?
    faqs_area_content: Yes. Auvik is SOC 2 Type II compliant, encrypts data in transit and at rest, supports
      role-based access control, single sign-on, and multi-factor authentication.
  - faqs_area_title: What is TrafficInsights?
    faqs_area_content: TrafficInsights is Auvik's flow-based traffic analysis feature that shows exactly
      which applications, users, and endpoints are consuming bandwidth, helping you troubleshoot slowness
      and identify security threats.
  - faqs_area_title: Does Auvik monitor cloud networks?
    faqs_area_content: Yes. Auvik monitors on-premise, hybrid, and public cloud network elements including
      AWS, Microsoft Azure, and VPN tunnels, with unified visibility across your entire footprint.
  - faqs_area_title: Does Auvik back up device configurations?
    faqs_area_content: Yes. Auvik automatically backs up configurations of supported devices, stores version
      history, and lets you compare configs and restore them with one click.
