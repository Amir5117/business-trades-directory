    alongside special Education pricing. All plans include the drag-and-drop 3D interior design editor
    and core model library; higher tiers unlock faster cloud rendering and team features.


    Free: $0 - basic 3D floor plan and decoration, limited model library, watermarked 2K renders, single
    user, ideal for hobbyists and trying out the tool.

    Pro (Monthly): $29/month - full model library access, unlimited 4K cloud renders, advanced design
    tools, no watermark, AR/VR walkthrough export, priority cloud rendering.

    Pro (Annual): $25/month billed yearly (about $299/year) - same Pro features at roughly 14% off the
    monthly rate; the most popular option for professional designers.

    Enterprise: Custom quote (typically from $99/month per seat) - 8K rendering, team project management,
    custom watermarks/branding, enterprise-grade rendering speed, API and SSO integration, dedicated account
    manager.

    Education Plan: Discounted pricing for verified students and educators - full Pro features with admin
    tools for classroom use; contact Coohom for current pricing.


    All Pro and Enterprise plans include unlimited projects, unlimited cloud storage, and access to Coohom''s
