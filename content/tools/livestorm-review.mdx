    <li><strong>Free:</strong> $0 forever — unlimited webinars, up to 10 attendees per event, 20-minute
    event cap, full registration pages, recordings, basic integrations</li>

    <li><strong>Pro:</strong> Starts at $99/month (monthly) or ~$70/month (annual) for 100 active contacts;

    analytics, Salesforce/HubSpot/Marketo integration, multi-language support</li>

    <li><strong>Business:</strong> Custom pricing — 3,000+ active contacts, up to 3,000 attendees per
    event, custom data retention, VIP customer support, Livestorm Learning access, dedicated CSM, multiple
    workspaces</li>

    <li><strong>Enterprise:</strong> Custom pricing — unlimited active contacts, unlimited workspaces,
    SAML SSO, custom security policies, advanced API access, white-glove onboarding, custom contract</li>

    </ul>
